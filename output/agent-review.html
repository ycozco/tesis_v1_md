SECCIÓN 1: VALIDACIÓN ESTRUCTURAL

Checklist Capítulo I: Planteamiento del Problema

  • [ ] 1.1 Descripción Realidad Problemática
  • [ ] Identifica 6+ problemas específicos (no genéricos)
  • [ ] Incluye contexto institucional/regulatorio
  • [ ] Magnitud del problema cuantificada o justificada

  • [ ] Coherencia: cada problema vinculado a objetivo

  • [ ] 1.2 Problema Principal

  • [ ] Redactado como pregunta clara
  • [ ] Identificables 3+ sub-problemas derivados
  • [ ] Scope: ni demasiado amplio ni muy reducido

  • [ ] Viabilidad dentro del alcance temporal

  • [ ] 1.3 Objetivos

  • [ ] Objetivo general singular, medible
  • [ ] Exactamente 5 objetivos específicos (OE1-OE5)
  • [ ] Cada OE es verificable (contiene métrica o verbo medible)
  • [ ] OE cubren todo el alcance del problema

  • [ ] Mapping: cada OE vinculado a VD

  • [ ] 1.4 Hipótesis

  • [ ] Hipótesis general (H1) + nula (H0)
  • [ ] Mínimo 3 sub-hipótesis (H1a, H1b, H1c...)
  • [ ] Hipótesis son testables (no tautologías)

  • [ ] Redacción clara: "Si...entonces..."

  • [ ] 1.5 Variables e Indicadores

  • [ ] VI operacional (categoría o escala clara)
  • [ ] Mínimo 4-5 VD identificadas
  • [ ] Cada VD tiene indicador cuantificable
  • [ ] Escalas de medición especificadas (0-1, Likert, %)

  • [ ] Rangos aceptables definidos explícitamente

  • [ ] 1.6 Viabilidad

  • [ ] Técnica: tecnologías existentes, datos accesibles
  • [ ] Operativa: equipo, timeline realista (5 meses)
  • [ ] Económica: presupuesto ≤ $2000 USD

  • [ ] Cada subsección incluye riesgos + mitigación

  • [ ] 1.7-1.9 Justificación, Alcance, Línea

  • [ ] Aportes teóricos → literatura específica
  • [ ] ROI económico estimado
  • [ ] Impacto social identificable
  • [ ] Alcance temático: qué incluye/excluye
  • [ ] Tipo investigación: aplicada cuantitativa

Checklist Capítulo II: Marco Teórico

  • [ ] 2.1 Antecedentes
  • [ ] Mínimo 5 dominios de investigación cubiertos
  • [ ] Cada dominio: 2-3 referencias de trabajos clave
  • [ ] Síntesis: cómo antecedentes justifican arquitectura híbrida
