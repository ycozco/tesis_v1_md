El reporte RAG debe citar o registrar internamente:

  • registro evaluado;
  • score y umbral;
  • top variables SHAP;
  • fuente recuperada;
  • version de dataset;
  • fecha de generacion;
  • advertencia cuando una variable sea proxy o sintetica controlada.
